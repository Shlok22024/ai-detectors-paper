# Can AI Detectors Actually Detect AI?

Research reproduction and generalization study. **Status: Phase 0 complete; paper, dataset and scope await owner approval.** No model results exist yet.

Read [the feasibility report](research/paper_feasibility.md) for the three-paper comparison, verified dataset counts, methodological risks and proposed laptop-friendly experiment. [Inspection evidence](research/feasibility_evidence.json) records source revisions and actual download checks.

Proposed target: a methodological reproduction of the cross-dataset design in [Xia et al. (EACL 2026)](https://aclanthology.org/2026.eacl-long.307/), using their released Mistral zero-shot texts, TF-IDF + logistic regression, and grouped abstracts-to-news evaluation.

The neural architecture and original split are not reproduced. Dataset preparation and modeling begin only after approval. Raw data and research scratch files are not included in this repository.
